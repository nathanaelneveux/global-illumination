## Shared workload and measurement rules

`src/cave_scene.rs` defines a finite 56×40×56 chamber within eight 32³ pages:
a broad lava floor, tall blue-banded spire, green ceiling crystals, scattered
wall torches and a five-by-five roof opening. There are 4,585 emitting faces and
121 fixed, exposed nonemitting wall/ceiling receivers. Lava emits RGB and IR;
crystals emit RGB and ionizing energy independently. These are normalized game
bands, not physical lava/thorium calibration. Opaque diffuse transport cannot
model real penetrating radiation.

Compute tests use Apple M4 / Metal, Rust 1.95, the locked development profile,
three explicit bounces, stable sequence offsets and all five scalar channels.
They have no viewport. Error is measured against independent high-sample
references, not coverage or bootstrap. Reported normalized p95 pools receiver /
channel / replicate errors `abs(estimate-reference)/(0.02+abs(reference))`.
Per-channel RMSE is also retained in the logs: aggregate improvement does not
mean every channel or receiver improves. References themselves are noisy.

Large logs/captures live under ignored `target/`. Exact branches retain the
harnesses. A failed or provisional trial is not silently replaced by a claim
that its verification passed.

## Spatial light hierarchy

Branch `experiment/gi-spatial-light-tree`, `18b66f8`.
This follows the receiver-dependent light-sampling principle described in
[PBRT's light sampling chapter](https://pbr-book.org/4ed/Light_Sources/Light_Sampling),
not a port of its implementation or the complete adaptive light-tree paper.

Below 32 emitting faces, retain the original power CDF. Otherwise build a balanced
spatial binary tree whose nodes bound emitter extent, power and face normals.
At each split, mix 95% approximate geometric importance with 5% power, with a
numerical branch-probability floor. The approximation selects samples; actual
visibility, emitted energy and MIS remain exact parts of the estimator.
Both forward selection and reverse PDF use the receiver's position and normal.
Cosine paths hitting emitters must use that same density, not the old global PDF.
Power includes IR/ionizing-only sources. No luminance-only rejection is allowed.

Tree nodes share the emitter storage binding, preserving the eight-storage-buffer
limit. A node occupies 64 GPU bytes; the cave adds 586,816 bytes for 9,169 nodes.
No per-receiver directional cache is added. Construction stays in the existing
worker-owned emitter snapshot; tree refitting/incremental rebuild is not yet
implemented. Analytic point lights still use their existing all-source loop:
this acceleration applies to emissive voxel faces, not thousands of Bevy lights.

Native PDF oracle: 3,872 selections match the CPU choice, and forward/reverse
density agrees within `2e-5` relative plus `1e-9` absolute. Unit tests check total
probability, selection density and extreme source-power ratios. Ordinary native
transport/edit parity retains RMS zero. Cave parity uses 8,192 paths and a
statistical tolerance after a 256-path comparison exposed small CPU/GPU floating
point path differences; it is not claimed to be bit-identical.

Equal-time study: 121 receivers, four paths per batch, eight disjoint blocks.
The common reference averages independent 32,768-path CDF and tree estimates at
sequence 1,048,576. Old shader archived from `bef988b`. Separate tracers avoid
alternating-emitter-upload cost. Eight short warmups after each long reference
dispatch are essential: earlier un-warmed budget-transition results are excluded.

| Sources | CDF → tree batch GPU p50 | Error at 8 ms, CDF → tree | At 16 ms | At 32 ms |
| --- | ---: | ---: | ---: | ---: |
| Mixed, 4,585 faces | .319 → .482 ms | .518 → .436 | .366 → .290 | .239 → .197 |
| Torches, 140 faces | .331 → .387 ms | .391 → .267 | .280 → .199 | .206 → .150 |
| Lava, 4,025 faces | .316 → .455 ms | .154 → .153 | .108 → .107 | .0756 → .0754 |

The hierarchy costs more per path. The win is error per compute time, **not** a
16–32% faster frame or an across-the-board variance reduction. At 32 ms, mixed
red RMSE worsens .0658 → .0790, while green .0627 → .0390, IR .0743 → .0448 and
ionizing .0469 → .0312 improve. The lava-only dim blue channel worsens while
dominant red/IR improve. This is a useful multi-source tradeoff, not perfect
spectral importance sampling.

An open-floor execution check had effectively unchanged worker p50
1.726 → 1.728 ms. Its later emissive identical-path assertion is inapplicable to
a sampler change and failed; the PDF/reference studies above are the relevant
checks. Regular suite: 141 passed / 25 ignored; strict all-target Clippy passed.

## Correlated edit differences

Branch `experiment/gi-edit-difference`, `ef88ee3`.
Inspired by [Residual Path Integrals for Re-rendering](https://www.iliyan.com/publications/ResidualPathIntegral/),
but **not an implementation of that paper's changed-object sampling/path mapping**.
This is the simpler correlated-path baseline: a settled old estimate plus a
signed old/new difference, or an adaptive control-variate coefficient per band.
The paper explicitly goes beyond that baseline.

Twenty-one cave receivers, eight disjoint blocks; independent 32,768-path old
prior/new reference. Fresh baseline uses 256 path evaluations. Adaptive control
spends 32 old/new pairs on an independent coefficient pilot and 96 pairs on the
correction: also 256 evaluations. Coefficients are covariance/variance clamped
to [0,1]. Pilot cost is included; obtaining the old settled prior is amortized.
The prior's sampling error remains. CPU workload times are similar (~20–22 ms);
this is not a GPU kernel benchmark. Signed corrections are not clamped.

| Change | Fresh normalized p95 | Adaptive difference p95 |
| --- | ---: | ---: |
| Torches dimmed by 30% | .2334 | .0329 |
| Torches off | .2136 | .1263 |
| Lava off | .1809 | .3641 |
| One extra roof block removed | .2287 | .0129 |
| Added interior rock wall | .2220 | .0755 |

The tiny roof edit in an already bright cave is near the old-prior error floor;
it does not establish a general 17× skylight response improvement. Per-band
results are mixed for some source changes. Unconditional old-plus-difference is
much worse for lava removal (.9945), and adaptive coefficients do not rescue it.
Keeping a common valid proposal is important: rebuilding only the new tree
decorrelates paths and gives away much of the benefit.

Decision: reject unconditional replacement; preserve a guarded follow-up.
Production needs bounded old geometry/proposal lifetime, new-source support
(union or a full-support alternative), prior-error accounting, new-receiver
fallback and a reliable cost/error selector. A large source removal must not
inherit the small-edit policy automatically. No production history policy was
changed. Focused study/cancellation check and strict Clippy pass.
Logs: `edit-difference-adaptive.log`, `edit-difference-clippy.log`.

## ReSTCV / retained temporal reuse

The [ReSTCV project](https://hercier.github.io/restcv/) combines reservoir reuse
with accumulated color contributions and signed control corrections. Source
audit pinned to [2fa972e](https://github.com/Hercier/ReSTCV/tree/2fa972eca7cf3c02a0e61291daf623e3278e9170),
especially `PathReservoir.slang`, `TemporalReuse.cs.slang`,
`SpatialReuse.cs.slang`, and `TemporalPathRetrace.cs.slang` under
`Source/RenderPasses/ReSTIRPTPass/`. No source was copied into this project.

The reservoir retains path/reconnection data and accumulated RGB, not just an
EMA. Selection uses an RGB luminance target; spatial correction includes
Jacobian/MIS terms and an albedo-ratio treatment. Temporal hybrid shifts can
trace both directions. Porting requires current visibility, dependency/lifetime
checks and a five-band target with support for invisible sources. It is not a
small extra blend on our existing face means.

Our estimator already accumulates full path contributions rather than shading
from one luminance-selected reservoir. **Inference:** adding reservoirs only to
correct their color noise is not justified. First make retained world-space
paths pay for their memory, reconnection and scheduling work. The previous
fresh-neighbor trial improved isolated error but worsened worker cost/freshness.
That result does not reject temporal reuse or ReSTCV; it explains why this pass
defers them rather than claiming a source audit is a performance experiment.

## Frozen incident approximation plus correction

Branch `experiment/gi-cache-control-variate`, `5ec4e1b`.
[Neural Two-Level Monte Carlo](https://arxiv.org/html/2412.04634v1) motivates an
approximation plus explicit residual, distinct from biased recursive cache
termination. Our independent non-neural test fits 4/16/64 equal-area bins in the
cosine hemisphere's uniform parameter domain, using 256 pilot paths. It freezes
the model, integrates its bins analytically and estimates `f-model` with 256
independent paths. No PDF change or recursive feedback; original path depth.

Eight blocks, 16 open-floor / 21 cave receivers, independent native 32,768-path
reference. Warm comparison gives the fitted model free and compares 256 new
paths. Cold comparison includes its 256 training paths against 512 fresh paths.

| Case | Fresh 256 | Corrected 4 bins | 16 bins | 64 bins | Fresh 512 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Open floor | .001262 | .000786 | .000515 | .000467 | .000562 |
| Mixed cave | .22869 | .23268 | .22506 | .25128 | .14468 |

Open-floor absolute error is already tiny. Cave gain at 16 bins is only ~1.6%
and per-band errors do not show a broad improvement; 64 bins regress. Coefficients
alone cost 100/340/1,300 bytes per face before metadata/alignment. Training cost
is roughly half the 512-path tracing cost. Reject this representation; do not
port it to WGSL. This does not disprove richer/neural control variates.
Area-integral/cancellation unit, native-reference study and strict Clippy pass.
Logs: `control-variate-study.log`, `control-variate-unit-final.log`,
`control-variate-clippy-final.log`.

### Keeping the knobs cheap

The first uniform-controlled implementation passed parity but increased the
nine-emissive-room native GPU median about 5–6%: baseline/candidate
1.917/2.008 and 1.902/2.017 ms. A fixed three-iteration ceiling alone still cost
1.931/1.986 ms; pipeline specialization without isolating the cutoff query cost
1.919/1.989 ms. These were not accepted as the final implementation.

`4aa283a` specializes depth/policy and moves the finite-cutoff query out of shared
shadow/default traversal. At most six face pipelines are created lazily on the
worker. Numeric reach changes within finite mode reuse the same pipeline. The
first use may delay a batch for compilation; it does not synchronously clear
the world or compile on the main thread.

Two final `shader_candidate_benchmark` runs compared the archived `8acdbb8` WGSL
against `4aa283a`'s exact shader/runtime diff, with no concurrent app/compiler,
no viewport, default 768/3/4 settings, 30 alternating warmed pairs each. Default
five-band means, moments, direct energy and sky match at identical paths.
